> **来源**：jx-dsp 任务/wait 专节 + oversea 台账 FE/BE 分流 + `doc-backend-sync` skill。

**类型**：Cursor Rule（`.mdc`）+ 可选 Skill（上游同步）

## 最佳实践（精炼）

### 强制触发

用户说「实现 / 开发 / 优化 / 修复」等 → **先**在 `docs/task/` 登记条目并在 `TASK.md` 注册，**再**编码。  
一次任务一次 commit；提交前更新状态。

### 状态符号（禁止 `- [ ]`）

| 符号 | 含义                                                  |
| ---- | ----------------------------------------------------- |
| `✅` | 已完成（本仓义务已落地）                              |
| `⚠️` | 部分完成                                              |
| `⭕️` | 待实现（本仓 FE 待办）                                |
| `⛔️` | 阻塞（须附原因与方案；仍属本仓义务）                  |
| `❎` | 确认先不做 / **FE 不跟**（纯 BE、等供给、产品未拍板） |

**分流**：纯后端/等字典 → `❎`，禁止用 `⛔️` 冒充本仓阻塞。重启 `❎` 须用户改回 `⛔️`/`⭕️`。

### 确认队列（可选双队列）

| 队列        | 确认方    | 未确认时                             |
| ----------- | --------- | ------------------------------------ |
| waitRD      | 后端      | 网络前 0 请求；已确认则实现并移除 QA |
| waitConfirm | PM/负责人 | 不臆造产品结论                       |

### 上游文档增量（Skill）

合同仓有新 commit → 侦测快照 → 开 Pn → 逐条实现+CDP+commit。见 [rule-fe-be-doc-sync](../rule-fe-be-doc-sync/) 与 glb chrome-debug。

### create/update 字段检查（可选加强）

大表单收口前：合同字段检查表 + 浏览器验收新建/编辑/拷贝与联动（脚本仅 `.playwright-mcp/`）。

## 验收清单

- [ ] 「实现」类请求会先改台账
- [ ] 状态只用约定 emoji
- [ ] FE/BE 边界不被 `⛔️` 误阻塞
