## 最佳实践（精炼）

### 强制触发

用户说「实现 / 开发 / 优化 / 修复」等 → **先**建 `docs/task/{id}.md`（活跃则登记 `TASK.md`），**再**编码。  
一次任务一次 commit；收工更新 `{id}.md` 并从活跃索引移除。

### 任务 ID（多人防冲突 · 强制）

**禁止**全局递增 `P1` / `P2`（多人并行会撞号、合并紊乱）。

| 规则    | 说明                                                                      |
| ------- | ------------------------------------------------------------------------- |
| 格式    | `{owner}{seq}`，全小写，无分隔符                                          |
| `owner` | `git config user.name` 规范化（小写、仅 `[a-z0-9]`）；也可用 GitHub login |
| `seq`   | 扫 `docs/task/{owner}*.md` 最大序号 + 1（**以文件为准**，不依赖索引）     |
| 示例    | `koujianfeng1`、`koujianfeng2`                                            |

### `TASK.md`：按人 → 按状态（降冲突 + 防膨胀）

| 真源      | 职责                               |
| --------- | ---------------------------------- |
| `{id}.md` | **全量档案**，历史保留             |
| `TASK.md` | **仅活跃**；`## {owner}` → `### ⭕️ | ⚠️  | ⛔️` |

```markdown
## koujianfeng

### ⭕️ 待实现

| ID           | 标题 | 路径              |
| ------------ | ---- | ----------------- |
| koujianfeng1 | …    | ./koujianfeng1.md |

### ⚠️ 部分完成

…

### ⛔️ 阻塞

…
```

- **只改自己的 `## {owner}`**；没有则在**文件末尾**新建整节（勿插进别人中间）
- 状态变更 = 在本人节内把行剪到对应子节；`✅`/`❎` → 写 `{id}.md` 后 **删行出看板**
- 禁止改别人的节、禁止全局重排、禁止把索引当编年史
- 合并：冲突面缩到「同一人 + 同一状态表」；保留双方新增行；偶发同 ID 则后提交者改 `seq`

### 状态符号（禁止 `- [ ]`）

| 符号 | 含义                                                  |
| ---- | ----------------------------------------------------- |
| `✅` | 已完成（本仓义务已落地）                              |
| `⚠️` | 部分完成                                              |
| `⭕️` | 待实现（本仓 FE 待办）                                |
| `⛔️` | 阻塞（须附原因与方案；仍属本仓义务）                  |
| `❎` | 确认先不做 / **FE 不跟**（纯 BE、等供给、产品未拍板） |

**分流**：纯后端/等字典 → `❎`，禁止用 `⛔️` 冒充本仓阻塞。重启 `❎` 须用户改回 `⛔️`/`⭕️`。

### 确认队列（可选双队列）

| 队列        | 确认方    | 未确认时                             |
| ----------- | --------- | ------------------------------------ |
| waitRD      | 后端      | 网络前 0 请求；已确认则实现并移除 QA |
| waitConfirm | PM/负责人 | 不臆造产品结论                       |

### 上游文档增量（Skill）

合同仓有新 commit → 侦测快照 → 开 `{owner}{seq}` → 逐条实现+CDP+commit。见 [rule-fe-be-doc-sync](../rule-fe-be-doc-sync/) 与 glb chrome-debug。
