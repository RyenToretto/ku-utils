# I18n 多语言

`@ku-utils/i18n` 提供轻量 `createI18n`、浏览器语言检测与消息合并，不绑定特定 UI 框架。

## 安装

```bash
pnpm add @ku-utils/i18n
```

## 使用示例

```typescript
import { createI18n, mergeMessages } from '@ku-utils/i18n';

const i18n = createI18n({
  locale: 'zh-CN',
  fallbackLocale: 'en',
  messages: {
    'zh-CN': { hello: '你好，{name}' },
    en: { hello: 'Hello, {name}' },
  },
});

console.log(i18n.t('hello', { name: 'ku-utils' }));
i18n.setLocale('en');

const merged = mergeMessages({ a: { b: 1 } }, { a: { c: 2 } });
```

## 导出 API

| 名称                  | 说明                                                |
| --------------------- | --------------------------------------------------- |
| `createI18n`          | 创建实例：`t`、`setLocale`、`addMessages`、`locale` |
| `detectBrowserLocale` | 根据 `navigator.language` 等检测语言                |
| `mergeMessages`       | 深度合并语言包对象                                  |

类型：`I18nInstance`、`I18nOptions`。
