# @ku-utils/ui

> Vue 3 业务组件库。

## 安装

```bash
pnpm add @ku-utils/ui
```

## 组件

`DuButton` · `DuCard` · `DuEmpty` · `DuModal` · `DuStatusTag`

## 使用

```ts
import { install } from '@ku-utils/ui';
import '@ku-utils/ui/style';

app.use(install);
```

```vue
<template>
  <DuButton type="primary">提交</DuButton>
</template>
```
