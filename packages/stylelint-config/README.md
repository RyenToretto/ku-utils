# @ku-utils/stylelint-config

> Stylelint CSS / SCSS 共享配置。

## 安装

```bash
pnpm add -D @ku-utils/stylelint-config stylelint
```

## 使用

CSS 项目 — `.stylelintrc`：

```json
{
  "extends": "@ku-utils/stylelint-config"
}
```

SCSS 项目：

```json
{
  "extends": "@ku-utils/stylelint-config/scss"
}
```

## 安装源

发布于 npmjs.org，直接 `pnpm add` 即可。
