# @ku-utils/prettier-config

> Prettier 共享配置。

## 安装

```bash
pnpm add -D @ku-utils/prettier-config prettier
```

## 使用

在 `package.json` 中添加：

```json
{
  "prettier": "@ku-utils/prettier-config"
}
```

或创建 `.prettierrc.js`：

```js
export { default } from '@ku-utils/prettier-config';
```

## 安装源

发布于 npmjs.org，直接 `pnpm add` 即可。
